# 릴리즈 노트

## v0.1.0 — 1단계(기반) · 2026-10-22

프리다이빙 강사와 센터를 잇는 아쿠아잡의 첫 버전. 공고·지원·제안은 2·3단계에서 열린다.

### 추가
- 도입부 슬라이드 4장 (v0 문구 인용, 프리다이빙으로 변경)
- 이메일 가입·로그인 (강사 / 센터), 세션 유지, 정지·퇴출 계정 차단 화면
- 강사 이력서: 한 화면에 질문 하나씩 작성, 이력서 수정, "센터에 내 프로필 공개" 스위치
- 센터 프로필과 센터 홈 (사업자등록증 확인 상태 안내)
- 서류 제출 (자격증·보험·응급처치·신분증 / 사업자등록증·여행업·대표자 신분증·대표강사 자격증), 상태 표시: 확인 대기 · 확인됨 · 곧 만료 · 만료 · 반려(사유)
- 관리자 서류 확인: 확인(유효기간 입력) / 반려(사유), 신분증 원본은 확인·반려·교체 시 삭제, "원본 삭제 대기" 재시도
- 여러 역할 계정은 상단 [관리자] [강사] [센터] 탭으로 전환
- 이용약관·개인정보처리방침 초안 페이지
- 앱 설치(PWA) 아이콘

### 보안
- 연락처·서류 원본은 본인과 관리자만 접근 (RLS·비공개 저장소)
- 정지·퇴출 계정은 쓰기 불가, 역할·상태는 앱에서 변경 불가
