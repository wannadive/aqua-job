# 릴리즈 노트

## v0.2.0 — 2단계 공고 · 2026-10-23

센터가 공고를 올리고, 강사가 지원하고, 센터가 선택하면 연락처가 열리는 흐름이 생겼다.

### 추가
- 공고 3종(수업 단위 · 소속 계약 · 투어 동행) 올리기·수정·마감. 종류별 필요 서류는 `verification_requirements` 기준으로만 확인한다.
- 관리자 `공고` 탭: 전체 공고를 최신순으로 읽기 전용 표시(상태 꼬리표·종류·센터·지역·날짜·단가·`N명 지원 · 선택 M/정원`·조회수), 전체/모집중/마감 필터. 지원은 상태만 읽고 연락처는 없다. 숨김·신고는 3단계.
- 구독 권한 자리: 유료 전환 후 상세 공개는 `구독하고 보기` 자리만 마련(`paid_mode`, 구독 테이블은 3단계).

### 바꿈
- 강사 홈 `지원 중` 숫자가 지원 현황의 `지원함` 탭 개수와 같아졌다(공고가 마감된 지원은 세지 않음). 불러오지 못하면 `다시 시도`가 보인다.
- 지원자 선택·지원 취소·지원이 서버에서 거절되면 창을 닫고 목록·숫자를 다시 불러온다. 지원 시트는 항상 닫힌다.
- 지원자 이력서에서 내용 없는 묶음은 숨김, 이메일 링크는 형식 확인 후 인코딩, 이력서를 열면 열려 있던 연락처 카드는 닫힘.

### 구조·DB
- 핀프렌즈 합류 대비: 공고 도메인(`lib/jobs`, `components/jobs`)은 셸을 import하지 않고, 센터 데이터는 `center_id → centers`, 공고·조회·지원 이름에 도메인 접두어. DB 정리 마이그레이션(`20261024_006_merge_ready`) 포함.

### 보안 보강 (`20261025_007_phase2_hardening`, 검사 `phase2_hardening_checks.sql`)
- 직접 조회(REST) 경로도 활성 계정·구독 확인: 정지·퇴출 센터는 이력서·지원 목록을 못 읽고, 센터의 이력서 열람(공개 이력서·지원자)은 센터 구독(`aquajob`) 필요(무료 기간엔 그대로 열림).
- 센터 소개(`center_profiles`)는 주인·관리자만 직접 읽고, 다른 사람은 공개 RPC로만 본다.
- 센터 구독 확인: 공고 수정·지원자 선택·연락처 열람(마감은 구독 없이도 됨). 공고 수정 때 서류 요건도 다시 확인.
- 공고 입력 한도: 마감일은 오늘부터 90일 안·수업일/투어 시작일 이전, 지역은 목록 안(DB `job_region_options()` = `REGION_OPTIONS`), 장소·근무 시간·행선지 100자, 자격 조건 20자. 공고 폼도 같은 한도로 미리 막는다.
- 공고 주인 회원 id(`owner_id`)·센터 프로필 `user_id`는 주인·관리자에게만. 센터 서류 사실은 `get_center_public_facts(centers.id)`로.
- 센터 지원자 탭의 `취소한 지원 보기` 없앰(취소한 지원은 센터에 더는 보이지 않는다). 지원 시트 한마디 아래 "연락처는 적지 말아 주세요. 선택되면 센터에 자동으로 열려요." 안내.

### 이전 작업 내용 (2단계 중간)
- 공개 공고 목록(`/jobs`)·상세(`/jobs/[id]`)·센터 프로필(`/centers/[id]`): 로그인 없이 열리는 공유 링크. 요약은 누구나, 상세 설명·센터 상세는 가입(또는 유료 전환 후 구독) 뒤에 열린다(`가입하고 보기` / `구독하고 보기`).
- 필터(전체·수업·소속·투어, 지역, 단가 공개 공고만), 마감 공고는 아래로·흐리게, 공유 버튼(링크 복사), 센터 공고 이력.
- 강사 지원하기: 공고 상세의 [지원하기] → 지원 시트(한마디 200자, 이력서 함께 전달 안내, 이력서 비어 있는 항목 안내). 공유 링크(`/jobs/[id]`)에서도 로그인한 강사는 그 자리에서 지원. 연락처는 지원 때 전달되지 않는다.
- 강사 지원 현황 탭: 지원함 / 선택됨 / 마감·미선택 / 취소함, 지원함 상태에서만 지원 취소. 강사 홈에 지원 중·총 지원 숫자와 선택됨 안내.
- 센터 지원자 탭: 내 모든 공고의 지원자(이름·공고명·상태·한마디·지원 시각)와 공고별 필터 칩, 공고 카드 [지원자 보기]는 그 공고로 바로 열림. 취소한 지원은 보이지 않는다(007부터 서버도 주지 않음).
- 지원자 이력서 보기(센터용): 이력서 항목, 본인이 입력한 값은 `(본인 입력)`, 서류는 확인된 유효 서류 사실만. 연락처는 없다.
- 지원자 선택: 확인 창(`선택하면 이 강사의 연락처가 열리고 되돌릴 수 없어요`) → 연락처 카드(휴대폰 전화 걸기·이메일 보내기, "이 연락처는 선택한 센터에만 보여요"). 이미 선택한 지원자는 [연락처 보기]를 눌렀을 때만 불러온다. 모집 인원이 차면 공고가 마감됐다고 안내하고 홈 현황 숫자도 바로 갱신.
- 도입부 마지막 장과 로그인 화면에 "공고 둘러보기" 링크, 강사 화면 공고 탭에 같은 목록·상세.

## v0.1.0 — 1단계(기반) · 2026-10-22

프리다이빙 강사와 센터를 잇는 아쿠아잡의 첫 버전. 공고·지원·제안은 2·3단계에서 열린다.

### 추가
- 도입부 슬라이드 4장 (v0 문구 인용, 프리다이빙으로 변경)
- 이메일 가입·로그인 (강사 / 센터), 세션 유지, 정지·퇴출 계정 차단 화면
- 강사 이력서: 한 화면에 질문 하나씩 작성, 이력서 수정, "센터에 내 프로필 공개" 스위치
- 센터 프로필과 센터 홈 (사업자등록증 확인 상태 안내)
- 서류 제출 (자격증·보험·응급처치·신분증 / 사업자등록증·여행업·대표자 신분증·대표강사 자격증), 상태 표시: 확인 대기 · 확인됨 · 곧 만료 · 만료 · 반려(사유)
- 관리자 서류 확인: 확인(유효기간 입력) / 반려(사유), 신분증 원본은 확인·반려·교체 시 삭제, "원본 삭제 대기" 재시도
- 여러 역할 계정은 상단 [관리자] [강사] [센터] 탭으로 전환
- 이용약관·개인정보처리방침 초안 페이지
- 앱 설치(PWA) 아이콘

### 보안
- 연락처·서류 원본은 본인과 관리자만 접근 (RLS·비공개 저장소)
- 정지·퇴출 계정은 쓰기 불가, 역할·상태는 앱에서 변경 불가
