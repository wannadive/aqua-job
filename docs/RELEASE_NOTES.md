# 릴리즈 노트

## 미출시 — 2단계 공고 (작업 중)

### 추가
- 공개 공고 목록(`/jobs`)·상세(`/jobs/[id]`)·센터 프로필(`/centers/[id]`): 로그인 없이 열리는 공유 링크. 요약은 누구나, 상세 설명·센터 상세는 가입(또는 유료 전환 후 구독) 뒤에 열린다(`가입하고 보기` / `구독하고 보기`).
- 필터(전체·수업·소속·투어, 지역, 단가 공개 공고만), 마감 공고는 아래로·흐리게, 공유 버튼(링크 복사), 센터 공고 이력.
- 강사 지원하기: 공고 상세의 [지원하기] → 지원 시트(한마디 200자, 이력서 함께 전달 안내, 이력서 비어 있는 항목 안내). 공유 링크(`/jobs/[id]`)에서도 로그인한 강사는 그 자리에서 지원. 연락처는 지원 때 전달되지 않는다.
- 강사 지원 현황 탭: 지원함 / 선택됨 / 마감·미선택 / 취소함, 지원함 상태에서만 지원 취소. 강사 홈에 지원 중·총 지원 숫자와 선택됨 안내.
- 도입부 마지막 장과 로그인 화면에 "공고 둘러보기" 링크, 강사 화면 공고 탭에 같은 목록·상세.

## v0.1.1 — 로그인 유지 · 2026-10-22

### 추가
- 로그인 화면에 "로그인 유지" 체크박스 (기본 켜짐). 끄면 브라우저(앱)를 닫을 때 로그아웃된다. 관리자 로그인에도 동일.

## v0.1.0 — 1단계(기반) · 2026-10-22

프리다이빙 강사와 센터를 잇는 아쿠아잡의 첫 버전. 공고·지원·제안은 2·3단계에서 열린다.

### 추가
- 도입부 슬라이드 4장 (v0 문구 인용, 프리다이빙으로 변경)
- 이메일 가입·로그인 (강사 / 센터), 세션 유지, 정지·퇴출 계정 차단 화면
- 강사 이력서: 한 화면에 질문 하나씩 작성, 이력서 수정, "센터에 내 프로필 공개" 스위치
- 센터 프로필과 센터 홈 (사업자등록증 확인 상태 안내)
- 서류 제출 (자격증·보험·응급처치·신분증 / 사업자등록증·여행업·대표자 신분증·대표강사 자격증), 상태 표시: 확인 대기 · 확인됨 · 곧 만료 · 만료 · 반려(사유)
- 관리자 서류 확인: 확인(유효기간 입력) / 반려(사유), 신분증 원본은 확인·반려·교체 시 삭제, "원본 삭제 대기" 재시도
- 여러 역할 계정은 상단 [관리자] [강사] [센터] 탭으로 전환
- 이용약관·개인정보처리방침 초안 페이지
- 앱 설치(PWA) 아이콘

### 보안
- 연락처·서류 원본은 본인과 관리자만 접근 (RLS·비공개 저장소)
- 정지·퇴출 계정은 쓰기 불가, 역할·상태는 앱에서 변경 불가
